# Ransomware Detection Application Using Blockchain-Based Logging System

## Project Overview

The Ransomware Detection Application Using Blockchain-Based Logging System is a cybersecurity solution designed to detect ransomware attacks in real time using Machine Learning and securely store detection logs using Blockchain technology. The system continuously monitors file activities, analyzes suspicious behavior, and generates alerts when potential ransomware threats are identified.

Traditional ransomware detection methods often rely on signature-based techniques, which struggle to detect new and evolving ransomware variants. This project addresses that limitation by implementing a behavior-based detection approach powered by a Random Forest Machine Learning model. To ensure the integrity and security of event logs, all detection records are stored in a blockchain-based logging system, making them tamper-resistant and transparent.

## Key Features

* Real-time file and directory monitoring
* Machine Learning-based ransomware detection using Random Forest
* Blockchain-powered secure and immutable logging
* User authentication and authorization
* Detection history and event tracking
* Instant alert and notification system
* Administrative dashboard for monitoring activities
* Report generation and analysis

## System Architecture

The system follows a modular architecture consisting of:

* **Authentication Module** – Handles user registration and login.
* **File Monitoring Module** – Monitors file system activities in real time.
* **Detection Engine** – Uses machine learning to identify ransomware behavior.
* **Blockchain Logging Module** – Stores detection events securely using blockchain concepts.
* **Alert System** – Generates notifications for detected threats.
* **Admin Dashboard** – Provides monitoring, management, and reporting functionalities.

This project demonstrates how Machine Learning and Blockchain technologies can be combined to create an effective ransomware detection and secure logging solution.
